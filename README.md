# キーンけし

教室のスピーカーから漏れる「キーン」という高い音を、MacBookのマイクで測り、スピーカーから打ち消し音を出してみるWebアプリ。

- 公開: https://kiin-keshi.vercel.app
- 開発: `pnpm dev` → http://localhost:5990 ／ テスト: `pnpm test`

## できること
1. **はかる** — 声向け加工を切ったマイク入力を 16384点FFT・8フレーム平均し、純音ピークを放物線補間で 1Hz 未満の精度で検出。滝グラフで時間変化も見える
2. **けしてみる** — 選んだ1本の純音を AudioWorklet で検波し、複素LMS(ニュートン型)で打ち消し音を合わせ続ける。
   聞き取り(周波数を0.01Hz単位に補正) → テスト音でスピーカー→マイクの伝わり方 G を測定 → 適応、の3段階。発散したら自動停止、出力に上限
3. **ほんとうに効く手** — 先生・事務室に渡す報告メモ(測定値つき)を作る

## 正直な限界
打ち消しで静かになるのは波長の1/10程度(15kHzで約2mm)の範囲、つまり**マイクの位置だけ**。耳の位置では効かない。
高い音への実際の対策は「音源(アンプ)を止める」「耳せん」。アプリもそう案内する。

## 構成
- `src/lib/spectrum.js` ピーク検出・帯域レベル・λ/10
- `src/lib/canceller.js` 打ち消しの状態機械＋サンプル単位エンジン(Worklet とテストで共通)
- `src/audio/anc-worklet.js` 薄い AudioWorklet ラッパ
- `test/` 部屋シミュレーション(遅れ37ms・反射・周波数推定ずれ・背景雑音)で 20dB 以上の打ち消し等を検証
